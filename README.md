# Industrial Robotics Ontology

An ontology developed to provide a **semantic representation of the operations, macro-movements, and components involved in an industrial robotic process**.

The ontology was created as part of my Bachelor's thesis on human-robot interaction with Universal Robots. It provides a structured representation of the concepts and relationships used by the graphical programming and monitoring tools developed in the other parts of the project.

The goal was to establish a semantic foundation that could be extended in future work, for example to enable **natural-language or voice-based interaction with the robotic system**.

The ontology was developed and modeled using **Protégé**.
